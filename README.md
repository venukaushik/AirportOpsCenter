# ✈️ Airport Operations Control Center (AOCC)

A fun learning project inspired by airport operations dashboards, built to explore modern web development and deployment workflows.

> **Disclaimer:** This is **not** intended to be a production-grade airport system. It is a personal project created for learning, experimentation, and improving development skills.

---

## 🚀 Project Goals

The primary objectives of this project are:

* Learn how to build a modular web application
* Practice organizing a larger codebase
* Learn Flask application development
* Learn Docker and Docker Compose
* Deploy the application inside containers
* Explore real-time dashboard concepts
* Experiment with modern JavaScript architecture

The focus is on learning by building rather than creating a production-ready application.
